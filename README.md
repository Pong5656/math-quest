- **ม.4:** เซต · ตรรกศาสตร์ · จำนวนจริง · ฟังก์ชัน · Expo/Log · เรขาคณิตวิเคราะห์
- **ม.5:** ตรีโกณมิติ · เมทริกซ์ · เวกเตอร์ · จำนวนเชิงซ้อน · หลักการนับ · ความน่าจะเป็น
- **ม.6:** ลำดับและอนุกรม · แคลคูลัส · สถิติศาสตร์ · ข้อมูล · ตัวแปรสุ่ม

> เนื้อหาอยู่ใน `src/data/m{4,5,6}l{1,2}.ts` — แก้/เพิ่มได้โดยตรง (ดู type ใน `src/lib/types.ts`)

## 🛠️ เทคโนโลยี

- Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS v4
- สูตรคณิตศาสตร์แสดงด้วย **KaTeX** · เอฟเฟกต์/อนิเมชัน **framer-motion**
- เกมมาริโอ/มินิเกมบน **Canvas API** (`src/components/GameCanvas.tsx`)
- เซฟความคืบหน้า/เหรียญ/ไอเทมใน **localStorage** (`mathquest_v1` ใน `src/lib/store.ts`) — ไม่ต้องใช้ฐานข้อมูล
- API `/api/health` พร้อมรองรับ PostgreSQL (drizzle) เมื่อตั้ง `DATABASE_URL` — แต่ Deploy ได้โดยไม่ต้องมี DB

## 🚀 เริ่มพัฒนา

```bash
npm install
npm run dev        # dev server ที่ http://localhost:3000
npm run build      # build production
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
```

## ☁️ Deploy บน Vercel

1. push โค้ดขึ้น GitHub
2. เปิด [vercel.com/new](https://vercel.com/new) → **Add New Project** → import repo → **Deploy**
3. (ไม่จำเป็น) ถ้าต้องการ `/api/health` เช็ค DB จริง: เพิ่ม Neon / Vercel Postgres → ตั้ง Env `DATABASE_URL` → รัน `npx drizzle-kit push`

ไม่ตั้งค่าอะไรก็เล่นได้ครบทุกโหมด — ความคืบหน้า/เหรียญ/ไอเทมเซฟในเบราว์เซอร์แต่ละเครื่อง
