## 📦 เทคโนโลยี

- Next.js (App Router) + React 19 + TypeScript
- Tailwind CSS v4 (ธีมพิกเซลกำหนดเองใน `src/app/globals.css`)
- Framer Motion (อนิเมชันโมดัล การ์ด สเต็ป)
- KaTeX (แสดงสมการคณิตศาสตร์)
- Drizzle ORM + PostgreSQL (กระดานคะแนน)
- Web Audio API (เสียง 8-Bit)
- ข้อมูลบทเรียน/โจทย์/สูตรเก็บเป็น TypeScript object (JSON-like) ใน `src/data/`

## 🚀 คำสั่งติดตั้งและรันในเครื่อง

```bash
npm install                 # ติดตั้ง dependencies
# สร้างไฟล์ .env (ถ้ายังไม่มี)
# DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db
npx drizzle-kit push        # สร้างตาราง player_scores
npm run dev                 # เปิด http://localhost:3000
```

ตรวจสอบก่อน deploy:

```bash
npx next typegen
npm run typecheck
npm run build
```

## ▲ Deploy ขึ้น Vercel

1. `git push` โปรเจกต์ขึ้น GitHub/GitLab
2. ใน Vercel → **Add New Project** → import repository
3. Framework Preset: **Next.js** (Build `npm run build`, Output อัตโนมัติ)
4. เพิ่ม Environment Variable `DATABASE_URL` (เช่น Neon / Supabase / Vercel Postgres)
5. Deploy → เข้า Vercel shell หรือใช้สกriptในเครื่องรัน `npx drizzle-kit push` กับ DATABASE_URL ของ production
6. เปิดโดเมนที่ได้ → พร้อมเล่นทันที

> หมายเหตุ: โหมดออฟไลน์/ไม่มีฐานข้อมูล — เกมยังเล่นได้ปกติทุกโหมด (ความคืบหน้าเก็บใน localStorage) เพียงแต่กระดานคะแนนรวมจะไม่แสดงข้อมูล

## 📚 เนื้อหา (18 บท)

- **ม.4 เล่ม 1**: เซต · ตรรกศาสตร์ · จำนวนจริง
- **ม.4 เล่ม 2**: ความสัมพันธ์และฟังก์ชัน · เอกซ์โพเนนเชียลและลอการิทึม · เรขาคณิตวิเคราะห์
- **ม.5 เล่ม 1**: ฟังก์ชันตรีโกณมิติ · เมทริกซ์ · เวกเตอร์ในสามมิติ
- **ม.5 เล่ม 2**: จำนวนเชิงซ้อน · หลักการนับเบื้องต้น · ความน่าจะเป็น
- **ม.6 เล่ม 1**: ลำดับและอนุกรม · แคลคูลัสเบื้องต้น
- **ม.6 เล่ม 2**: ความหมายของสถิติศาสตร์และข้อมูล · ข้อมูลเชิงคุณภาพ · ข้อมูลเชิงปริมาณ · ตัวแปรสุ่มและการแจกแจงความน่าจะเป็น

ทุกบท: โจทย์ปรนัยอย่างน้อย 12 ข้อ (🟢🟡🔴) พร้อม **วิธีทำทีละขั้น + ทริกคิดลัด + สูตรที่ใช้** และมี **วิธีจำสูตร (mnemonic) + พิสูจน์ย่อ**
